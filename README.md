# 桌宠 Deskpet

Windows 桌面宠物合集（Electron）。角色立绘用 Codex 的 `image_gen` 生成透明底动作图，WebGL 着色器让头发随风飘动、拖动时有惯性。可以在右键菜单 → **角色 / 皮肤** 里随时切换角色。

| 角色 | 皮肤 |
| --- | --- |
| **初音未来** | 即刻轮回 · いますぐ輪廻（默认）、经典 · 淡彩 |
| **福贺久留美**（FX战士久留美） | FX战士 · 白色连衣裙 |
| **芙宁娜**（原神） | 魔法偶像 · 舞台装 |

## 安装

到 [Releases](https://github.com/wldinhy/miku-deskpet/releases/latest) 下载（仅 Windows x64）：

- **Deskpet-Setup-x.x.x.exe**：安装版，可自选安装位置，自动创建桌面和开始菜单快捷方式，可在系统“应用”里卸载。
- **Deskpet-Portable-x.x.x.exe**：免安装版，双击即用。

安装程序没有代码签名，第一次运行时 Windows 可能弹出“已保护你的电脑”，点 **更多信息 → 仍要运行** 即可。从旧版「Miku 桌宠」升级时直接安装新版即可，好感度、待办等存档会自动迁移。

## 从源码运行

需要 Node.js 18+。

```bash
npm install
npm start
```

装好依赖后，也可以双击 `启动桌宠.vbs` 直接启动（不弹命令行窗口）。`.npmrc` 已配置 npmmirror 的 Electron 镜像，国内网络也能顺利安装。

自己打包安装程序：`npm run dist`，产物在 `dist/`。

## 通用互动

| 操作 | 反应 |
| --- | --- |
| 单击头 / 鼠标在头上来回蹭 | 摸头，开心脸红，冒爱心 |
| 单击脸颊 | 戳脸，鼓起腮帮子 |
| 单击身体（连戳） | 吓一跳 / 挠痒笑个不停 |
| 单击头发两侧 | 拽头发，会生气 |
| 单击腿 | 跳一下 |
| 双击 | 转个圈（正面 → 侧面 → 背面） |
| 按住拖动 | 拎起来；用力甩出去会被抛飞、撞墙反弹 |
| 右键 | 打开菜单 |

右键菜单还有：
- **小功能**：番茄钟、待办便签、定时提醒、猜拳、今日运势、好感度与记录
- **设置**：大小、不透明度、喝水 / 久坐提醒、打瞌睡时间、置顶、自由散步、重力、音效、说话声、整点报时、安静模式、开机自启

她们会自己散步、东张西望、坐下休息，长时间没人理会就打瞌睡（点一下叫醒）。好感度会随互动增长，解锁更亲密的台词。音乐和音效全部由 WebAudio 实时合成。托盘图标：左键显示 / 隐藏，右键打开菜单。

## 福贺久留美（FX战士久留美）

20 岁的特待生女大学生，用打工攒下的 30 万日元挑战 FX，目标是赢回 2000 万。平时认真好学、开朗可爱，一被行情逼急就会贪心暴走。

- **互动**：看看行情（盯着手机看盘）、啃 FX 教材、向 K 线祈祷、暴走模式、请她吃饭团、递一罐咖啡
- **FX 模拟盘**（小功能）：USD/JPY 随机行情 K 线图，用 30 万虚拟本金选仓位和杠杆做多 / 做空。她会跟着盈亏欢呼、祈祷、暴走，利确时撒日元，保证金维持率跌破 50% 就被强制平仓、当场崩溃。持仓时脚下的徽标会显示实时盈亏。**行情完全随机生成，仅供娱乐，不构成任何投资建议。**
- 被用力摔到地上时不是晕倒，而是“被强制平仓了……”
- **深夜盯盘**：晚上裹着开衫守在电脑前（可设为入夜自动开始）
- 今日运势、台词都换成了她的口吻

## 芙宁娜（原神）

枫丹的大明星。爱演、爱蛋糕，嘴上狂妄，其实胆小又爱哭。造型是魔法偶像风的舞台装。

- **互动**：登台致意（摘帽谢幕）、召唤沙龙成员（三只水之小伙伴绕着她转）、万众狂欢（撒彩带）、逞强一下（腿在抖）、哭给你看、唱歌跳舞、请她吃蛋糕、陪她喝下午茶
- **歌剧院审判**（小功能）：输入你的“罪状”，比如“今天又熬夜了”，她会郑重宣判——有罪就罚你去睡觉、去喝水；无罪就赏你一块蛋糕
- **下午茶**：每天下午三点，她会邀请你喝下午茶（需开启整点报时）
- 被用力摔到地上会先哭出来，然后马上逞强装作没事
- **谢幕之后**：夜晚她会独自坐在聚光灯下（可设为入夜自动开始）
- 偶尔会站在雨里发一会儿呆

## 目录

```
main.js            主进程：透明置顶窗口、拖拽 / 抛掷 / 下落 / 散步物理、菜单、托盘、存档
preload.js         IPC 白名单
js/character.js    角色与皮肤定义、立绘加载与 WebGL 渲染（头发飘动、眨眼 / 说话叠层、像素级命中判断）
js/app.js          动作状态机、交互、自主行为、各角色的专属动作
js/features.js     番茄钟、待办、提醒、猜拳、运势、好感度面板、FX 模拟盘、歌剧院审判
js/audio.js        合成音效与原创小曲
js/lines*.js       各角色 / 皮肤的台词
assets/gen/        初音 · 经典皮肤立绘
assets/skins/      其他皮肤立绘（rinne、kurumi、furina）
tools/             用 Codex CLI 批量生成立绘的脚本（在 WSL 中运行）
```

## 重新生成立绘

在装有 Codex CLI 并已登录的 WSL 中：

```bash
bash tools/gen-kurumi.sh wave d "standing facing the viewer, cheerfully waving ..."
bash tools/gen-kurumi-batch.sh 0 3   # 参数：起始行 步长；已存在的立绘会跳过
```

初音的立绘对应 `tools/gen.sh`、`tools/gen-rinne.sh`，芙宁娜对应 `tools/gen-furina.sh`、`tools/gen-furina-batch.sh`。
